Web search (Tavily)

    

    

    
Jarvis can search the web for current facts once a Tavily key is saved below. Results with Chinese, Japanese or Korean text are dropped. Costs: each region is one Tavily search.

  
Music · songs from a folder

    

    
Say "Jarvis, play something random", "play a song by <artist>" or "play <song name>"; "stop the music" or "next song" to end or change it. Internet radio and podcasts: "play Radio 538", "play jazz radio", "play the latest episode of <podcast>" (a live stream: plays until you stop it, or until the timer set here ends). Only a short clip of each song is played. While it plays, the robot shows the song title under its face and the same speaking visuals as for a voice. Set the folder above, then Save & restart.

  
Home Assistant · voice control of the house

    

    

    

    
Enter the address and a long-lived access token under API keys below (Home Assistant: your profile, Security, Long-lived access tokens), then Save & restart. Spoken commands like "turn off the kitchen light" are then done instantly, without the brain. Kinds in the first box are done at once, kinds in the second only after you say yes, everything else (locks, alarms, garage doors) is refused. Every action is listed here.

Mood: how Jarvis sounds

    

    

    
Applies at once, no restart. You can also say "be cheerful", "be calm", "be serious", "be dry" or "back to normal". The mood is a short extra instruction in the prompt and a face on the robot's screen.

  

  

    
Memory: what Jarvis remembers

    

    

    

    
Short notes the memory module writes after each conversation, kept in the file data/.memory.yaml of the server folder on this PC. They are added to Jarvis's prompt whichever brain answers. Turn memory off under Conversation settings above.
